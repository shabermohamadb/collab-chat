# CollabSpace Frontend

React + TypeScript + Vite + Tailwind CSS + Socket.IO Client user interface for the multi-user collaborative chat platform.

## Features

- **🚀 Real-Time Reactive State**: Instant synchronization with Socket.IO channels.
- **💬 Shared Conversation `@AI` Teammate**: Seamless mention autocomplete and contextual markdown responses.
- **🎨 Modern Slate Workspace Theme**: Clean, responsive layout with mobile drawer and desktop multi-pane views.
- **🧵 Thread Support**: Nested reply drawers for deep discussions.
- **⚡ Typing & Presence Indicators**: Real-time typing indicators and live status badges.
- **📎 Media & File Uploads**: Image previews, lightbox view, and document attachments.

## Running Locally

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start Vite Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173`.
